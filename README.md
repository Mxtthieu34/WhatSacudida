# Sacudida ⚡

Mensajería instantánea en el navegador con chat, grupos, notas de voz, GIFs/stickers,
videollamadas y notificaciones push. Sin backend propio: todo funciona sobre MQTT
público + PeerJS + localStorage.

## ✨ Funciones

- Chat 1-a-1 y grupos
- Notas de voz, archivos, GIFs y stickers
- Emojis
- Apodos y bloqueo de contactos
- Videollamadas 1-a-1 y grupales (WebRTC vía PeerJS)
- Compartir pantalla (con o sin audio)
- Notificaciones push (PWA con Service Worker)
- Modo claro / oscuro, temas de color y fondos personalizables
- Avisos offline: si te escriben mientras estás desconectado, lo ves al volver
- Panel de administrador (banear usuarios y ver reportes)
